Your clinic never misses a booking again. How it works
1
Receive on any channel the client wants
Generic webhook, Telegram (text + voice notes), WhatsApp Business (text + voice). Each channel toggles on/off per client in a single config row — turn off what they don't need, no code changes.
2
Understand with AI (voice + text)
Voice notes transcribe via Whisper, then OpenAI reads intent against the client's config — book, reschedule, cancel, or general question — and replies in a warm, human tone matching the clinic's language.
3
Book, change, or cancel in one shot
Appointment logs to the Google Sheets database as the source of truth and syncs to Google Calendar so the clinic's existing workflow is untouched. Changes and cancellations update both in lockstep.
4
Automatic reminders — 24h and same-day
A scheduled job scans the Sheet each hour and fires reminders via the patient's original channel (SMS, email, Telegram, or WhatsApp) at 24h before and ~1h before the visit. No-shows drop significantly.
5
Admin stays in the loop on errors only
Every error, timeout, or ambiguous request that the AI can't safely resolve triggers an instant notification to the admin — so 99% of bookings run hands-off, and the 1% edge cases get human eyes fast.
