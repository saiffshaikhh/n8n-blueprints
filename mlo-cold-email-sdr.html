How I'd run the campaign
1
Build the MLO list properly — not just a scrape
NMLS Consumer Access for the verified license + brokerage data, LinkedIn Sales Nav filtered by "Mortgage Loan Officer" + active markets, Apollo cross-reference for emails, Apify scrapers for state-by-state broker directories. Filter by NMLS license active + recent activity. Verify every email through a waterfall (Hunter → Snov → Findymail → ZeroBounce) so bounce rate stays under 2%.
2
Set Instantly up for 90%+ inbox placement
8–12 sending mailboxes across 3+ root domains with separate aliases per mailbox. Full SPF / DKIM / DMARC setup, 2-week warmup before any cold sends, 25–35 daily sends per mailbox max. Smart sending on, mail merge fallback handling, time-zone matched send windows for US business hours. Verified list only — no catch-alls, no role-based.
3
Write copy that lands with MLOs specifically
MLOs care about: more closed loans, better lead quality, faster pre-qual times, beating rate competitors, and building a referral pipeline outside Realtor dependence. 4-step sequence: short value-prop opener → social proof from a comparable broker → soft CTA (case study link) → break-up email. No "I noticed you're a top MLO" garbage. Subject lines under 5 words.
4
Triage replies twice a day, call warm leads same-day
Morning + afternoon reply pass. Positive → call within 2 hours during 9-5 EST. Objection → handle inline + book if appropriate. Out of office → reschedule sequence. Wrong contact → ask for the right person. Calendly link only after a verbal yes on the call — booking-form qualification beats a cold link.
5
Daily report, EOD EST, no exceptions
Slack message before EOD EST: emails sent, replies (positive/neutral/negative), calls made, conversations had, meetings booked, list of booked MLOs with NMLS + brokerage + qualification notes. Weekly recap on Friday: what's working, what to test next week, mailbox health, deliverability flags.
6
Push to close — earn the Stage 2 jump fast
Trial week 1: focus on volume + booking discipline so you see the funnel works. Week 2: shadow your closer, learn the pitch, pre-qualify deeper so booked calls convert. Goal: by month 2, run discovery + close independently on 30% commission. Sales is the goal, not booking.
