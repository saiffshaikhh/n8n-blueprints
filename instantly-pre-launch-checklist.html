1
List upload
Get the leads in cleanly, no garbage rows, no duplicates.
  • ✓
    CSV is UTF-8 encoded so accented characters don't break (resave as UTF-8 from Sheets if needed)
  • ✓
    Required columns present: email, first_name, plus any custom variables your copy uses
  • ✓
    Email column has been verified (target under 2% bounce rate, run through ZeroBounce or Bouncer if not done)
  • ✓
    Duplicates removed across email, including across past Instantly campaigns to avoid re-pitching the same person
  • ✓
    Role-based addresses (info@, support@, hello@) and catch-alls stripped before upload
Red flag. If bounce rate is over 5% in the first 200 sends, pause the campaign and re-verify the list. Domain reputation drops fast and recovers slowly.
2
Field mapping
Every variable in the email must map to a real column.
  • ✓
    Every {{variable}} in your sequence has a column mapped on upload
  • ✓
    First name is title-cased ("john" auto-corrects to "John" so it doesn't look like a bot)
  • ✓
    Fallback values set on optional variables (if a row is missing personalisation, fallback prevents an empty paragraph)
  • ✓
    No typos in variable names (e.g. {{firstname}} vs {{first_name}} is the most common cause of merge tag failures)
  • ✓
    Test row sent to your own inbox renders all variables correctly
3
Sending settings
Configured to keep the inbox placement above 90% and stay out of spam.
  • ✓
    Mailboxes warmed for 14 days minimum before any cold sends (Instantly warmup tool, daily ramp-up)
  • ✓
    SPF, DKIM, and DMARC verified on every sending domain (use MXToolbox to confirm)
  • ✓
    Daily send limit set to 25 to 35 emails per mailbox, not 100+
  • ✓
    Send window aligned to your prospect's time zone, not yours (9 AM to 5 PM local for the recipient)
  • ✓
    Smart sending toggle ON so duplicates and re-engaged contacts are skipped
  • ✓
    Mailbox rotation enabled across all campaign mailboxes
  • ✓
    Tracking pixel either OFF or domain-aliased (default Instantly pixel is a known spam signal in 2026)
Red flag. Sending more than 50 emails per mailbox per day is the single fastest way to get flagged. Stay under 35 even if Instantly lets you go higher.
4
Copy review
Quick pass on what you wrote, looking for the things that quietly destroy reply rate.
  • ✓
    Subject line under 5 words and lowercase, no spam-trigger words (free, guaranteed, $$$)
  • ✓
    Email body under 80 words for the first touch
  • ✓
    One clear CTA only (no "book a call AND download AND reply")
  • ✓
    No images, no logos, no fancy HTML signatures (plain text reads as personal, not bulk)
  • ✓
    Unsubscribe option present on follow-up emails (soft "let me know if not relevant" line is enough for cold sends)
  • ✓
    Personalisation variable actually personalises ("hope you're doing well" doesn't count)
  • ✓
    Spam-tested through Mail-Tester, score 9 out of 10 minimum
5
Launch sanity check
Last 5 minutes before you press go.
  • ✓
    Test email sent to your own inbox, all variables render, links work, signature is clean
  • ✓
    Test email also opens correctly on mobile (most prospects open on phones first)
  • ✓
    Reply-to address goes to a real inbox you actually monitor
  • ✓
    Out-of-office and auto-replies routed away from your main inbox
  • ✓
    First send batch capped to 50 to 100 emails so you can pause if anything looks off
  • ✓
    Calendar block set for 24 hours after launch to monitor opens, replies, bounces
