Post-Job Review Routing — Two-Path Flow
Trigger
Job marked complete in BookingKoala → Make webhook fires
↓
24-hour wait → Initial follow-up SMS sent via GHL: "How did your clean go today?"
↓
Client replies → Make reads response → routes to appropriate path
Happy Path
Positive reply detected by AI sentiment layer
SMS sent with direct Google review link
Contact tagged "Review Requested" in GHL
If no review posted in 3 days → one gentle reminder
Contact moves to retention campaign sequence
Unhappy Path — Private
Negative reply or concern detected
Make alerts owner via SMS + GHL notification immediately
Contact flagged "Needs Attention" in pipeline — visible to team
Client receives empathetic reply: "We'd love to make it right…"
No public review link sent until owner resolves the issue

Phase 2 — AI Voice Receptionist
What it handles
After-hours inbound calls — greets caller, collects service info, provides quote range, offers to text a booking link.
GHL integration
Call transcription logged to GHL contact. Missed call auto-triggers SMS follow-up via existing Make scenario.
Stack (recommendation)
Vapi or Bland AI for voice layer — both integrate with GHL natively and support custom knowledge base training.
Handoff protocol
If caller requests human: call forwarded to owner's mobile. GHL flags contact for morning callback if no answer.
Scope note
Phase 2 scoped after Phase 1 is live and stable. Architecture designed in Phase 1 to accommodate voice without rebuilding.
Readiness
Full capability in this area. Voice AI on GHL backend is an active build type — timeline and pricing flagged separately.
